### 第一部分：C语言源代码实现

我们将使用**邻接矩阵（Adjacency Matrix）**来存储图，因为它易于理解且代码实现相对简单。程序包含城市、路线（含费用、时间、交通工具）等信息。

**C**

```
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <limits.h>

#define MAX_CITIES 20
#define INF 999999  // 定义无穷大，表示不可达

// 定义路线信息的结构体
typedef struct {
    int cost;       // 费用
    int time;       // 时间（小时）
    int type;       // 交通类型：0-无通路, 1-飞机, 2-火车
} Route;

// 定义图的结构体
typedef struct {
    char cityNames[MAX_CITIES][20]; // 存储城市名称
    Route matrix[MAX_CITIES][MAX_CITIES]; // 邻接矩阵
    int numCities; // 当前城市数量
} Graph;

// 全局图变量
Graph g;

// 初始化图数据（为了演示，这里预设了一些数据）
void initGraph() {
    g.numCities = 5;
    strcpy(g.cityNames[0], "北京");
    strcpy(g.cityNames[1], "上海");
    strcpy(g.cityNames[2], "西安");
    strcpy(g.cityNames[3], "成都");
    strcpy(g.cityNames[4], "广州");

    // 初始化所有路径为无穷大
    for (int i = 0; i < MAX_CITIES; i++) {
        for (int j = 0; j < MAX_CITIES; j++) {
            g.matrix[i][j].cost = INF;
            g.matrix[i][j].time = INF;
            g.matrix[i][j].type = 0;
        }
    }

    // 手动添加一些路线 (双向)
    // 北京(0) - 上海(1): 飞机, 费用1000, 时间2h
    g.matrix[0][1].cost = 1000; g.matrix[0][1].time = 2; g.matrix[0][1].type = 1;
    g.matrix[1][0].cost = 1000; g.matrix[1][0].time = 2; g.matrix[1][0].type = 1;

    // 北京(0) - 西安(2): 火车, 费用300, 时间6h
    g.matrix[0][2].cost = 300; g.matrix[0][2].time = 6; g.matrix[0][2].type = 2;
    g.matrix[2][0].cost = 300; g.matrix[2][0].time = 6; g.matrix[2][0].type = 2;

    // 西安(2) - 成都(3): 火车, 费用200, 时间4h
    g.matrix[2][3].cost = 200; g.matrix[2][3].time = 4; g.matrix[2][3].type = 2;
    g.matrix[3][2].cost = 200; g.matrix[3][2].time = 4; g.matrix[3][2].type = 2;

    // 上海(1) - 广州(4): 飞机, 费用1200, 时间3h
    g.matrix[1][4].cost = 1200; g.matrix[1][4].time = 3; g.matrix[1][4].type = 1;
    g.matrix[4][1].cost = 1200; g.matrix[4][1].time = 3; g.matrix[4][1].type = 1;
  
    // 成都(3) - 广州(4): 火车, 费用500, 时间10h
    g.matrix[3][4].cost = 500; g.matrix[3][4].time = 10; g.matrix[3][4].type = 2;
    g.matrix[4][3].cost = 500; g.matrix[4][3].time = 10; g.matrix[4][3].type = 2;

    // 北京(0) - 广州(4): 直飞, 费用2000, 时间3h
    g.matrix[0][4].cost = 2000; g.matrix[0][4].time = 3; g.matrix[0][4].type = 1;
    g.matrix[4][0].cost = 2000; g.matrix[4][0].time = 3; g.matrix[4][0].type = 1;
}

// 根据城市名获取索引
int getCityIndex(char *name) {
    for (int i = 0; i < g.numCities; i++) {
        if (strcmp(g.cityNames[i], name) == 0) {
            return i;
        }
    }
    return -1;
}

// 打印路径
void printPath(int parent[], int j) {
    if (parent[j] == -1) return;
    printPath(parent, parent[j]);
    printf(" -> %s", g.cityNames[j]);
}

// Dijkstra算法核心
// strategy: 1-最短时间, 2-最低成本, 3-最少中转
void dijkstra(int startNode, int endNode, int strategy) {
    int dist[MAX_CITIES];    // 存储起始点到各点的最短距离（权重）
    int visited[MAX_CITIES]; // 标记是否已访问
    int parent[MAX_CITIES];  // 存储路径前驱节点

    // 初始化
    for (int i = 0; i < g.numCities; i++) {
        dist[i] = INF;
        visited[i] = 0;
        parent[i] = -1;
    }
    dist[startNode] = 0;

    for (int count = 0; count < g.numCities - 1; count++) {
        // 1. 寻找未访问节点中dist最小的节点
        int min = INF, u = -1;
        for (int v = 0; v < g.numCities; v++) {
            if (!visited[v] && dist[v] <= min) {
                min = dist[v];
                u = v;
            }
        }

        if (u == -1 || u == endNode) break; // 无法到达或已找到终点
        visited[u] = 1;

        // 2. 更新相邻节点的距离
        for (int v = 0; v < g.numCities; v++) {
            // 如果存在连接且未访问
            if (!visited[v] && g.matrix[u][v].type != 0) {
                int weight = 0;
              
                // 根据策略决定权重
                if (strategy == 1) weight = g.matrix[u][v].time;       // 时间
                else if (strategy == 2) weight = g.matrix[u][v].cost;  // 成本
                else if (strategy == 3) weight = 1;                    // 中转次数(每条边权重为1)

                if (dist[u] != INF && dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    parent[v] = u;
                }
            }
        }
    }

    // 输出结果
    if (dist[endNode] == INF) {
        printf("\n抱歉，从 %s 到 %s 没有可达的路线。\n", g.cityNames[startNode], g.cityNames[endNode]);
    } else {
        printf("\n================ 推荐路线 ================\n");
        printf("起点: %s  终点: %s\n", g.cityNames[startNode], g.cityNames[endNode]);
        printf("策略: %s\n", strategy == 1 ? "最短时间" : (strategy == 2 ? "最低成本" : "最少中转"));
      
        printf("路线详情: %s", g.cityNames[startNode]);
        printPath(parent, endNode);
      
        printf("\n\n统计数据:\n");
        // 这里需要重新回溯计算具体的总时间和总费用，因为dist只存了其中一种
        int totalCost = 0;
        int totalTime = 0;
        int curr = endNode;
        int transfers = 0;
        while(parent[curr] != -1) {
            int prev = parent[curr];
            totalCost += g.matrix[prev][curr].cost;
            totalTime += g.matrix[prev][curr].time;
            transfers++;
            curr = prev;
        }
      
        printf("总费用: %d 元\n", totalCost);
        printf("总时间: %d 小时\n", totalTime);
        printf("中转次数: %d 次 (乘坐交通工具 %d 次)\n", transfers > 0 ? transfers - 1 : 0, transfers);
        printf("==========================================\n");
    }
}

int main() {
    initGraph();
    char startName[20], endName[20];
    int choice;

    while (1) {
        printf("\n######## 旅行信息顾问系统 ########\n");
        printf("当前可用城市: ");
        for(int i=0; i<g.numCities; i++) printf("%s ", g.cityNames[i]);
        printf("\n");
      
        printf("请输入起点城市: ");
        scanf("%s", startName);
        int start = getCityIndex(startName);

        printf("请输入终点城市: ");
        scanf("%s", endName);
        int end = getCityIndex(endName);

        if (start == -1 || end == -1) {
            printf("错误：输入的城市不存在，请检查拼写。\n");
            continue;
        }

        printf("\n请选择偏好:\n");
        printf("1. 最短旅行时间\n");
        printf("2. 最低旅行成本\n");
        printf("3. 最少转换次数\n");
        printf("0. 退出系统\n");
        printf("请输入选项: ");
        scanf("%d", &choice);

        if (choice == 0) break;
        if (choice < 1 || choice > 3) {
            printf("无效选项！\n");
            continue;
        }

        dijkstra(start, end, choice);
      
        printf("\n按回车键继续...");
        getchar(); getchar(); // 暂停
    }
    return 0;
}
```

### 第二部分：实验指导书与任务书回答（报告素材）

你需要将以下内容整理到你的Word文档或实验报告中。

#### （1）如何设计数据结构来表示程序所需的信息？

为了有效地表示城市、交通路径及其多维属性（时间、费用），本项目采用了**图（Graph）**作为逻辑结构，并在C语言中通过**邻接矩阵（Adjacency Matrix）**进行物理存储。

* **顶点（Vertex）：** 代表城市。使用一个一维字符数组 `cityNames[MAX_CITIES][20]` 存储城市名称，数组下标即为城市的唯一ID。
* **边（Edge）：** 代表城市间的交通路线。使用一个二维结构体数组 `matrix[MAX_CITIES][MAX_CITIES]` 表示。
  * 结构体 `Route` 包含三个成员变量：
    * `cost` (int): 路径费用（权重1）。
    * `time` (int): 路径耗时（权重2）。
    * `type` (int): 交通工具类型（标识位，亦可用于判断边是否存在）。
* **设计理由：** 考虑到城市数量相对固定且不会特别庞大（通常在几十个以内），邻接矩阵能够以 **$O(1)$** 的时间复杂度快速查询任意两个城市之间是否存在路径及路径属性。虽然空间复杂度为 **$O(N^2)$**，但在城市数量较少时完全可以接受，且相比邻接表实现更直观。

#### （2）请阐明并描述您的算法。

本程序的核心在于寻找“最佳”路径，这属于图论中的 **单源最短路径问题** 。我采用了经典的  **Dijkstra算法** （迪杰斯特拉算法），并根据用户偏好进行了适配：

1. **算法初始化：**
   * 创建 `dist[]` 数组记录起点到各点的最小权值，初始化为无穷大（INF），起点为0。
   * 创建 `visited[]` 数组标记节点是否已确定最短路。
   * 创建 `parent[]` 数组用于记录路径的前驱节点，以便最后回溯打印路线。
2. **权重动态选择（核心逻辑）：**
   * Dijkstra算法通常处理单一权重。为了满足三个不同的需求，我在算法的“松弛（Relaxation）”步骤中动态选择权重：
     * 若用户选  **(1) 最短时间** ：比较 `dist[v]` 与 `dist[u] + matrix[u][v].time`。
     * 若用户选  **(2) 最低成本** ：比较 `dist[v]` 与 `dist[u] + matrix[u][v].cost`。
     * 若用户选  **(3) 最少转换** ：将所有存在的边权重视为  **1** 。此时最短路径即为经过边数最少的路径（BFS思想的Dijkstra实现）。
3. **迭代过程：**
   * 在未访问的集合中找到 `dist` 最小的节点 **$u$**。
   * 标记 **$u$** 为已访问。
   * 遍历 **$u$** 的所有邻接点 **$v$**，根据选定的权重策略更新 `dist[v]` 和 `parent[v]`。
   * 重复直至遍历完所有节点或找到终点。

#### （3）请说明你们方案的正确性和有效性。

* **正确性：** Dijkstra算法是解决**无负权边**图的最短路径问题的贪心算法。由于旅行的时间、费用和中转次数均不可能为负数，因此该算法在理论上能保证找到最优解。程序通过动态切换权重参数，正确地复用了同一套核心逻辑来解决三个子问题。
* **有效性：**
  * **时间复杂度：** 使用邻接矩阵实现的Dijkstra算法时间复杂度为 **$O(V^2)$**，其中 **$V$** 是城市数量。对于本课程设计（**$V \le 20$**）的规模，计算是瞬间完成的。
  * **空间复杂度：** **$O(V^2)$** 用于存储矩阵，对于 **$V=20$**，仅需存储400个结构体，内存占用极小。

#### （4）功能演示（测试用例）

**预设数据图示：**

* 北京--上海 (1000元, 2h)
* 北京--西安 (300元, 6h)
* 西安--成都 (200元, 4h)
* 成都--广州 (500元, 10h)
* 上海--广州 (1200元, 3h)
* 北京--广州 (直飞, 2000元, 3h)

**测试 1：北京 -> 广州 (策略：最低成本)**

* **输入：** 起点：北京，终点：广州，偏好：2 (最低成本)
* **预期输出：** 路线：北京 -> 西安 -> 成都 -> 广州。总费用：300+200+500 = 1000元。
* **分析：** 虽然直飞很快，但费用2000元；经上海转机需2200元；经西安-成都转火车最便宜。

**测试 2：北京 -> 广州 (策略：最短时间)**

* **输入：** 起点：北京，终点：广州，偏好：1 (最短时间)
* **预期输出：** 路线：北京 -> 广州。总时间：3小时。
* **分析：** 直飞最快。虽然经上海转机也是(2+3=5h)，但直飞只需3h。

**测试 3：北京 -> 成都 (策略：最少转换)**

* **输入：** 起点：北京，终点：成都，偏好：3 (最少转换)
* **预期输出：** 路线：北京 -> 西安 -> 成都 (中转1次)
* **分析：** 当前数据没有北京直飞成都的航线，必须中转。经西安中转次数最少（如果数据中有直达航班，程序会优先选择直达）。

#### （5）讨论算法的优点和局限性。

**优点：**

1. **通用性强：** 通过抽象权重的概念，用同一个算法解决了时间、金钱、跳数三个维度的问题，代码复用率高。
2. **扩展性好：** 如果将来需要增加“最舒适（根据交通工具打分）”的偏好，只需在结构体中增加字段并修改Dijkstra中的权重获取逻辑即可。
3. **精确性：** 相比于启发式搜索（如A*），Dijkstra能保证在有限节点内找到绝对最优解。

**局限性：**

1. **未处理多重边：** 目前的数据结构（邻接矩阵）在两个城市间只能存储一条“最佳”边。现实中，北京到上海可能同时有高铁和飞机。目前的方案需要预处理，只存入一条边，或者需要改为邻接表+链表来支持多重边。
2. **未考虑中转等待时间：** 目前计算的“时间”仅为路程耗时，未包含换乘时的等待时间（Layover time），这在现实旅行规划中是关键因素。
3. **静态数据：** 所有的路线是预先写死的，无法实时查询网络数据。
